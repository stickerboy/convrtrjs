## Improvements
### Search
- Rebuilt search on Pagefind's new component UI, for both the search flyout and the Advanced search page
- Search results now show each page's tags as coloured badges, matching the tags used across the rest of the site
- The results summary now highlights the number of results and your search term
- The Filters panel on the Advanced search page now opens automatically when there are results
- Restyled the Filters panel to match the previous search design, with each tag on its own row and result counts shown as badges
- Restyled the search box to match the site's other inputs, with the Clear button joined to the end of the box
- The Advanced search page now uses a two-column layout, with filters on the left and results on the right
- Search result excerpts are longer on the Advanced search page, so there's more context for each result
- Refreshed search colours in dark mode

## Bug fixes
- Fixed "There are no result" typo in the search summary when nothing matches
- Fixed the "Advanced search" link in the search flyout missing its trailing slash

### Improvements
- Updated 11ty to the latest version [3.1.6](https://github.com/11ty/buildawesome/releases/tag/v3.1.6)
- Updated [Pagefind](https://github.com/Pagefind/pagefind/releases) from `1.4.0` to `1.5.2`, and moved from the legacy `PagefindUI` to the new component UI
- Added a custom `<convrtr-summary>` component to replace Pagefind's built-in summary, so the result count and search term can be styled
- Added a custom result template so result tags render as badges
- Shared search summary logic between the search flyout and the Advanced search page
- Overrode Pagefind's default component styles so the search box and filters follow the site's Bootstrap theme in both light and dark mode
